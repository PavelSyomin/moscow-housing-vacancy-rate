# Вакантность жилья в Москве

Код для статьи «Оценка ваканости жилья в Москве», принятой в InterCarto.InterGIS (2025). Для воспроизведения надо пройти по тетрадкам от первой до четвёртой. В тетрадках есть достаточно подробные комментарии. Пятая — опционально: там пара вспомогательных графиков. Карты создавались отдельно — кода для них здесь нет.

Первоначально работа проведена в рамках конкурса Института Генплана Москвы «Исследуй город» (2024). Для статьи обновлены некоторые исходные датасеты и улучшен код.
