# Данные для тетрадок

Здесь находятся как «входные» данные, так и результаты (промежуточные и итоговые). При выполнении кода промеуточные и итоговые результаты перезапишутся, поэтому будьте осторожны: скопируйте их отсюда или поменяйте пути сохранения в тетрадках.

В папках `ce` и `gisgkh` лежат исходные файлы для скриптов (`scripts`), создающих файлы `flats.parquet` и `flats_area.parquet`. По общему правилу, запускать и использовать их нет нужды, но для полноты эти данные лежат здесь. Пояснения по источникам получения сведений есть в тетрадках.
